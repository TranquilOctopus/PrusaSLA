## Uncertain items

- **Row 11 (Support on model)**: Lychee's toggle is a yes/no per point; ours is a tri-state, because a point that says nothing has to follow the object's `support_buildplate_only`. Where the branch is anchored on the model is still up to the algorithm, and `support_max_weight_on_model` still limits the total branch length that may end there, so Lychee's notion of a single switch that only permits the start is wider than ours.
- **Row 17/18 (Raft)**: Our raft is still the pad, a print-bed adhesion base with a cavity, where Lychee's and Chitubox's rafts are shaped plates. `raft_type` is a named bundle of pad values (`RaftPreset.hpp`), so the types are exact, but "raft" in Lychee is not a superset of what the pad generator can express: a grid or honeycomb in Lychee is an infill pattern of the whole raft, ours is a pattern cut into the inside of ours (`raft_infill`, M2.14b2a), which is why it is a second setting and not a raft type, and the type names may need renaming against Lychee and Chitubox.
- **Rows 6, 7, 9, 10 (built, still no UI)**: `tip_shape`, `knot_radius`, `stem_sides` and `stem_taper` are stored on the point, survive undo and the 3MF, and the support tree mesh builds them (M2.16b), but there is no UI control for them, so a user cannot set them yet.
- **Row 21 (Overhang angle)**: `support_critical_angle` governs stick/junction angles, not the overhang detection threshold. The auto-generation overhang threshold is still hard-coded or not exposed.
- **Row 17/18 (Raft)**: Our "pad" is architecturally different from Lychee's "raft" (pad is a print-bed adhesion base with cavity; raft in Lychee is a disposable interface layer). The parity is approximate.
- **Row 21 (Overhang angle)**: the threshold is measured on the sampled overhang outline: the horizontal run of a sample is its distance to the layer below, the vertical run the layer height. A wall (no horizontal run) is 90 degrees, which the default keeps, so today's points are unchanged. `support_critical_angle` is a different knob, the stick junction angle.
